Usage

Type go <keyword> in your browser address bar to jump straight to a service. Any other query is sent to SearXNG.

go jellyfinopen the matching service
goshow this keyword list
anything elsesearch SearXNG

Add as a browser search engine

Chrome / Edge (desktop)

  1. Open Settings → Search engine (or chrome://settings/searchEngines, edge://settings/search).
  2. Under Site search click Add / Add from sites and apps.
  3. Fill in:
    NameGoBar
    Shortcutgo
    URL with %shttp://THIS-HOST/?q=%s

Firefox (desktop)

  1. Open this page in a tab. Firefox auto-detects the OpenSearch entry and shows Add "GoBar" next to the address bar — click it. (If you don't see it: right-click the page → Search Settings → add http://THIS-HOST/?q=%s under "One-click search engines".)
  2. Optionally set GoBar as the default search engine in Settings → Search so the address bar routes through it.

Android (Chrome / Firefox)

  1. Chrome: Settings → Search engine → Add in the search engine selection is not available; install via desktop sync, or use a custom New Tab app pointing at this URL.
  2. Firefox for Android: Settings → Search → Add search engine, name GoBar, URL http://THIS-HOST/?q=%s.

Tip: keep SearXNG as a second engine — GoBar forwards everything that is not a go command to it, so one engine covers both.
